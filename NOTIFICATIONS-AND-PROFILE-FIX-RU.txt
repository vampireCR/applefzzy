APPLE BOOK — ИСПРАВЛЕНИЕ ПРОФИЛЕЙ И УВЕДОМЛЕНИЙ

Что исправлено в этих файлах:
1. Настройки видимости профиля (Everyone / Friends only) и видимости времени посещения теперь входят в публичные данные профиля и сохраняются в Supabase. По умолчанию профиль открыт всем. Если выбрать Friends only, профиль будет виден только друзьям.
2. Кнопка Save profile теперь ожидает завершения облачного сохранения и показывает ошибку, если Supabase отклонил запись.
3. Действия уведомлений (прочитать, сохранить, удалить, отметить все прочитанными, удалить прочитанные, удалить все несохранённые) и переключатели типов уведомлений принудительно запускают облачную синхронизацию.
4. Добавлены явные права на таблицу applebook_user_state для авторизованных пользователей. RLS по-прежнему ограничивает доступ только собственной строкой пользователя.
5. Исправлено визуальное расположение вкладок All / Unread / Saved, чтобы они не слипались.

УСТАНОВКА
1. Распакуйте архив прямо в корень репозитория GitHub Pages, чтобы index.html и cloud.js лежали в корне, а не во вложенной папке.
2. В Supabase → SQL Editor выполните файл profiles-permissions-fix.sql.
3. Замените index.html и cloud.js файлами из архива.
4. Дождитесь GitHub Pages deployment и обновите сайт через Ctrl+F5.

ВАЖНО
В этой версии уведомления приложения хранятся в applebook_user_state как персональный список пользователя. Синхронизация списка и его кнопок между повторными входами одного аккаунта исправлена. Полноценная доставка каждого нового уведомления другому пользователю в реальном времени требует отдельного серверного маршрута/политик для таблицы notifications; этот архив не выдаёт локальное создание уведомления за уже готовую межпользовательскую доставку.
