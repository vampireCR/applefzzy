APPLE BOOK — ИСПРАВЛЕНИЕ УДАЛЕНИЯ АККАУНТА

ПОЧЕМУ ПОЯВЛЯЛОСЬ СООБЩЕНИЕ
В предыдущей версии cloud.js удаление аккаунта было намеренно заглушено. В этой версии заглушка удалена: кнопка вызывает серверную Supabase Edge Function applebook-admin, которая удаляет пользователя через Supabase Auth Admin API.

ЧТО СДЕЛАТЬ
1. В Supabase открой Edge Functions.
2. Создай функцию с точным именем: applebook-admin.
3. Вставь полный код из supabase/functions/applebook-admin/index.ts и нажми Deploy.
4. В Secrets функции проверь переменные:
   - SUPABASE_URL
   - SUPABASE_ANON_KEY
   - SUPABASE_SERVICE_ROLE_KEY
   - APPLEBOOK_REDIRECT_URL=https://vampirecr.github.io/applefzzy/
   Service Role Key хранится ТОЛЬКО в Secrets Supabase. Не вставляй его в index.html, cloud.js или GitHub.
5. В Authentication -> URL Configuration добавь https://vampirecr.github.io/applefzzy/ в Redirect URLs.
6. Загрузи в корень публикуемого GitHub Pages каталога файлы index.html, cloud.js и _headers, а также папку supabase/functions/applebook-admin/ (она нужна для хранения исходника функции; само по себе наличие папки в GitHub не разворачивает Edge Function).
7. Важно: Edge Function надо развернуть именно в Supabase Dashboard или через Supabase CLI. Загрузка файлов на GitHub Pages не разворачивает её автоматически.
8. Дождись публикации GitHub Pages, открой сайт через Ctrl+F5 и повтори удаление.

КАК РАБОТАЕТ УДАЛЕНИЕ
- В настройках нажми Delete my account, затем повторно подтверди действие.
- Владелец (owner) защищён от удаления через этот интерфейс.
- Удаление чужого аккаунта разрешено только Head Admin/Owner и только для аккаунта с более низким рангом.
- Если функция не развернута или не настроены Secrets, сайт покажет серверную ошибку и НЕ будет имитировать успешное удаление.
- Удаление пользователя из Supabase Auth может не пройти, если в базе существуют внешние ключи без ON DELETE CASCADE/SET NULL. В таком случае пришли точный текст ошибки; не удаляй таблицы вручную.

БЕЗОПАСНОСТЬ
Никогда не публикуй SUPABASE_SERVICE_ROLE_KEY. Если он когда-либо попадал в клиентский код или публичный репозиторий, немедленно перевыпусти его в Supabase.
